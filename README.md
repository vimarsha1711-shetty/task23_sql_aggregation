# Task 23: SQL Aggregation Basics

## About This Task
This task is part of my data analysis internship at Veda Technology. I used MySQL Workbench to practice SQL queries on employee data.

## Tools Used
- MySQL Workbench
- SQL

## Work Done
I practiced the following SQL functions:

1. COUNT() - Counted the total number of employees.
2. SUM() - Calculated the total salary.
3. AVG() - Calculated the average salary.
4. MIN() - Found the minimum salary.
5. MAX() - Found the maximum salary.
6. GROUP BY - Grouped employees by department.

I also calculated employee count, total salary, average salary, highest salary, and minimum salary for each department.

## What I Learned
I learned how to use SQL aggregate functions and group employee data by department.
